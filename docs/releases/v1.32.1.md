This release makes StationPlay's releases source only, adds a way to report security problems privately, and lists what the tested image held.

## New

- **Source only.** Releases no longer include a ready-made image. Every install already builds StationPlay from the zip, TrueNAS included, so nothing changes for you.
- **What was tested, listed.** Each release comes with `stationplay-<version>-packages.txt`: every package in the image StationPlay's tests ran in, at its exact version, with a link to its source.
- **Reporting a security problem.** [SECURITY.md](https://github.com/egadgetboy/stationplay/blob/main/SECURITY.md) says how to tell us privately, and when to expect an answer.

## Changed

- **Ideas and bug reports are welcome as issues.** StationPlay doesn't accept code contributions for now.
- **Platforms.** Fire TV is no longer listed. StationPlay's apps are for Android phones, tablets, Google TV and Android TV, and are coming for iPhone, iPad, Apple TV and Roku.

## Good to know

- **Nothing in StationPlay itself changes.** Your stations, settings and apps work as in 1.32.0.
- **Your build gets Debian's packages from Debian** on the day it's built, so its FFmpeg can be newer than the one tested. `/opt/stationplay/third-party-packages.txt`, in your image, lists what you have.

## Updating

`stationplay-1.32.1.zip` is the app (it unzips to `src`), `stationplay.yaml` is for TrueNAS SCALE, and `docker-compose.yml` is for everything else.

Unzip `stationplay-1.32.1.zip` over `src`, then change only the version in `image:` to `stationplay:1.32.1` (see [Updating](https://github.com/egadgetboy/stationplay#updating)). Your stations, settings, sign-ins and Plex token are kept. Nothing in the database changes, so no copy of it is made. For a new install, see [Install](https://github.com/egadgetboy/stationplay#install).

## Rolling back

To go back to 1.32.0 (see [Rolling back](https://github.com/egadgetboy/stationplay#rolling-back)):

1. Stop StationPlay.
2. Unzip `stationplay-1.32.0.zip` over `src`.
3. Change `image:` back to `stationplay:1.32.0`, and start it.

Everything is kept as it is.
