One check now decides what each person may watch, the same way everywhere, and it keeps checking a movie or episode while it plays.

## New

- **Limits apply while a title plays.** Say you move your son to the Kid level halfway through an R-rated movie. Within about 15 seconds his app stops it and says "This title is restricted." Before, a title was checked only as it started, so it played to the end. A title his new level still allows plays on. The access log notes each stop.
- **One check, everywhere.** Stations as they air, Media as it starts and while it plays, and every list now all ask the same check. Hidden episodes and Clean audio will use it too once they're built. An episode hidden for someone will then be blocked only while it airs, and its Station stays. A level that needs Clean audio will block a program until its Clean audio is ready.

## Fixed

- **The station editor's previews** (the Intro Bumper and the Up Next Banner) no longer play or name what's on a Station an Admin blocked for the person making the preview.

## Updating

`tapioca-1.40.0.zip` is the source. Update the way the banner says, or see [Updating](https://github.com/egadgetboy/tapioca-server#updating). The database doesn't change, so tapiOca makes no copy. Apps that don't yet know "This title is restricted" show their usual "can't play" message when a title stops this way.

## Rolling back

Use the image `ghcr.io/egadgetboy/tapioca-server:1.39.0` (see [Rolling back](https://github.com/egadgetboy/tapioca-server#rolling-back)). The database didn't change, so there's no copy to put back and nothing is lost. Titles are then checked only as they start, as before.
