tapiOca now checks the HTTPS addresses it reaches against an up-to-date list of trusted certificate authorities.

## Fixed

- **Trusted certificates brought up to date.** tapiOca's list of trusted certificate authorities (certifi) still trusted some root certificates whose intermediate keys had been compromised (GHSA-6q48-6c7w-9gw2). It now uses the updated list, 2026.10.18, which drops them. Nothing else changes.

## Updating

`tapioca-1.44.2.zip` is the source. Update the way the banner says, or see [Updating](https://github.com/egadgetboy/tapioca-server#updating). The database doesn't change, so tapiOca doesn't back it up first.

## Rolling back

Use the image `ghcr.io/egadgetboy/tapioca-server:1.44.1` (see [Rolling back](https://github.com/egadgetboy/tapioca-server#rolling-back)). It runs on this database as it is, so there's nothing to put back and nothing is lost.
