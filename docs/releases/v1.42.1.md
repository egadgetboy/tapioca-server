Someone picked with their PIN on Who's tuning in? can no longer make anything that works on another device: only a password, an invite code or a linked code can.

## Fixed

- **A PIN can't link an app.** Before, someone picked with their PIN on a shared TV or tablet could use that sign-in to link another app by its code. That made a 30-day sign-in that worked anywhere, even after **Remove this device**. No app did this by itself, but the server allowed it.
- **To change a PIN or a password, sign in with your password first.** Someone with only a PIN asks an Admin. An Admin's Light PIN still gives their Admin tools at home, but not these.
- **A new PIN ends the sign-ins the old one made,** whether you or an Admin sets it.
- **A saved Sonarr or Radarr key goes only to its saved address.** Changing the address asks for the key again.
- **Each sign-in now notes how it was made:** a password, an invite code, a linked code, a PIN, picking someone with no PIN, or a trusted network.

## Updating

`tapioca-1.42.1.zip` is the source. Update the way the banner says, or see [Updating](https://github.com/egadgetboy/tapioca-server#updating). The database changes, so tapiOca saves a copy first (`backups/before-1.42.1-<date>.db`). Nobody is signed out. Sign-ins from before the update keep watching and keep their Admin tools. To link an app, make an invite code or an API token, change a PIN or a password, add someone, make someone an Admin, change trusted networks or Away from home, or download or restore a backup, sign in with your password once. Check **Signed-in apps** on the **Access** tab, and sign out any you don't know.

## Rolling back

Follow [Rolling back](https://github.com/egadgetboy/tapioca-server#rolling-back): stop tapiOca, put `backups/before-1.42.1-<date>.db` back as `stationplay.db`, delete `stationplay.db-wal` and `stationplay.db-shm`, and use the image `ghcr.io/egadgetboy/tapioca-server:1.42.0`. Changes made since the update are lost. Sign-ins from before the update come back; sign-ins made since don't. 1.42.0 has the gap this release closes.
