# Glossary

Admin
: A person who can do everything in tapiOca. There's always at least one.

Alert
: A note to Admins that something needs attention, shown in the header and log, and sent to up to 3 addresses if you choose.

API token
: A secret, shown once, that lets a script use tapiOca's API.


Broken files list
: The list of files that can't play properly. They're kept off the air on every Station.

Burn-in protection
: The slight, steady movement of what's in the corner, so it can't mark an OLED or plasma TV.

Converted copy
: A copy made as a title plays, with the picture made again, for a device that can't play the file.

Deep scan
: The overnight check that decodes each file in full.


Dolby Vision profile 5
: Dolby Vision with no standard picture inside. Stations list it as **Unsupported**.

Even sound
: Episodes brought to the same loudness, −24 LUFS, so the volume doesn't jump.

Feature Presentation
: A special: a movie night at set times.

Full sign-in, Light sign-in
: An Admin's choice: a password every time (Full), or a password once on each device, then a PIN there at home (Light).

GPU
: A graphics processor that converts video with far less work. tapiOca uses Intel, AMD and NVIDIA GPUs.

Guide
: What's on each Station over the next 2 days, given to other apps as XMLTV.

HDR, SDR
: High and standard dynamic range: two kinds of picture color. Stations play in SDR.

HLS
: A video format many players use. Each Station is available as HLS at home.

Home port, public port
: Port 3310, for home only (the page, Plex's tuner and the streams), and port 3311, for the page and apps from the internet, where sign-in is always required.

INFO station
: Station 99, which comes with a new tapiOca: what's new, tips and counts.

Intro Bumper
: A card or video that plays when a Station's stream starts.

Invite code
: A one-time code, good for 7 days, to get someone on a device without a password.

Linked device
: A device that opens on **Who's tuning in?**, because someone signed in on it.

M3U playlist
: The list of Stations other apps read, at `/stations.m3u`.

Marathon
: A special: three episodes of one show in a row.

Media
: Your movies and shows, on demand in tapiOca's apps.

Media folder
: One collection of your shows or movies: Plex's, or one tapiOca reads itself.

NAT loopback
: A router feature that lets home devices use the home's internet address. Without it, tapiOca can't check its outside address from home.

NFO file
: A small file beside a video with its title, plot, rating and other details.

PIN
: A 4-digit number a person gives when they pick themselves on a shared device.

Plex Pass
: Plex's paid plan, needed to watch Stations in Plex, find intro markers, and block Stations for Plex users.

Quick check
: A fast check that a file opens, and its picture and sound decode at five points.

Repackaged copy
: A copy that keeps the picture as it is and converts only the sound.

Restricted program
: A program someone may not watch, blocked for them while it airs.

Reverse proxy
: A program that takes HTTPS from the internet and passes it to tapiOca's public port.

Smart stations
: Stations made in one step from a filter, one or one for each value.


Stand-in
: A program that plays for the rest of a failed program's time.

Station
: A live, always-on stream of your own movies and shows, with a number, a name, a logo and a guide.

Station ID card
: A short card after each program, with a jingle.

Trusted network, trusted proxy
: A network whose devices skip signing in; a proxy whose word about its visitors tapiOca believes.

Tuner
: What other apps use to watch your Stations; also each Station tapiOca can play at once.

Up Next Banner
: A banner near each program's end saying what's next.

User
: A person who watches what their Viewing Level allows, and can make a few Stations.

Viewing Level
: What a person can see, by rating, Media folder, genre, tag, collection or studio.

VPN
: A private network, such as Tailscale or WireGuard, that reaches tapiOca as if at home.

Who's tuning in?
: The screen a shared device opens on, where each person picks themselves.

XMLTV
: The guide format other apps read, at `/xmltv.xml` (Plex) and `/guide.xml`.
