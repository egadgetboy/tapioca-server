# About this manual

This manual covers **tapiOca server 1.44.4**, released November 2, 2026. It replaces every earlier edition: only the newest one applies.

**Who it's for:** the server owner, who installs tapiOca and keeps it running, and **Admins**, who run it from its page. People who only watch need the *tapiOca Apps Manual*.

**What it covers:** everything a server owner and an Admin can see and do in 1.44.4, from installing to troubleshooting. It describes only what's released. tapiOca is in beta, for testing only, so keep it up to date and use the newest edition of this manual.

### Conventions

- **Bold** marks what's on screen, exactly as tapiOca's page shows it: tabs, buttons, settings and choices, such as **Setup**, **Save station** or **Shuffle**.
- `Code` marks what you type or read exactly: addresses, file names, commands and settings in a file, such as `http://192.168.1.20:3310` or `TZ`.
- Arrows show a path through menus: **Settings → Live TV & DVR**.
- Examples use made-up addresses, such as `192.168.1.20` and `tv.example.com`. Use your own.
- The Settings reference lists every setting with its choices and default.
- A dashed box marks where a screenshot will go in a later edition.

> **Tip:** A tip is good practice that saves time or trouble.

> **Note:** A note adds a detail worth knowing.

> **Important:** An important note warns of something that could lose data, expose something you meant to keep private, or stop playback.

### Words used throughout

- **Station:** one of tapiOca's live, always-on streams of your own movies and shows, with a guide.
- **Media:** your movies and shows, played on demand in tapiOca's apps.
- **Media folder:** one collection of your shows or movies, either Plex's or one tapiOca reads itself.
- **The page:** tapiOca's own web page, where Admins run the server.
- **The apps:** tapiOca's own apps for Android, iPhone and iPad, and Roku.
